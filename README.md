# Data Foundry Inc.

Hero section for a BI and data architecture consulting site.

## Preview locally

Open `index.html` in any browser—no build step required:

```bash
open index.html
```

Or from the project folder:

```bash
cd ~/data-foundry-inc && open index.html
```

## Customize

- Replace `[Your Name]` in `index.html` with your name.
- Update `hello@datafoundry.inc` mailto links when your email is ready.

## Stack

Plain HTML and CSS. Fonts load from Google Fonts (Fraunces + DM Sans).
